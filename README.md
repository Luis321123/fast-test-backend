## 📖 About

A **NestJS** backend scaffold set up to write and run tests quickly,
with ESLint + Prettier for consistent code.

## ✨ Features

- NestJS app with a standard `src/` + `test/` layout
- ESLint + Prettier preconfigured
- `nest start` ready to go

## 🚀 Getting Started

```bash
git clone https://github.com/Luis321123/fast-test-backend.git
cd fast-test-backend && npm install
npm run start
```
